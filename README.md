# Steal an AI — GPU Tycoon

A browser-based idle/tycoon game where you recruit AI models walking down a red carpet.

## Currencies
- **🎮 GPU Coins** — Spend to recruit models from the red carpet
- **🖥️ CPU Coins** — Earned passively from owned models; convert 10:1 into GPU
- **🧠 RAM Coins** — Rare currency from prestiging; buys legendary "OG" models

## Model Tiers
| Tier | Color | Examples |
|------|-------|----------|
| Common | Gray | Nemotron 3B, Phi-3 Mini, Gemma 2B |
| Rare | Blue | Nemotron 7B, Llama 3 8B, Mistral 7B |
| Epic | Purple | Nemotron Ultra, Llama 3 70B, Command R+ |
| Legendary | Gold | GPT-4o Mini, Claude 3.5 Sonnet, Gemini 1.5 Pro |
| **OG Legend** | Rainbow | **GPT-1o, Claude Fable 5, Opus 5** (RAM only) |

## Controls
- **Click** a walking model to recruit (if affordable)
- **Right-click** a walking model for details
- **C** — Convert CPU → GPU
- **F** — Force spawn (5 GPU)
- **S** — Toggle game speed (1x/2x/5x/10x)
- **P** — Prestige (when available)
- **Esc** — Close modal

## Prestige
Reset everything (keep RAM + prestige level) to earn RAM Coins based on lifetime GPU earned. Each prestige level increases RAM gain by 50%.

## Play
Open `index.html` in any modern browser. Progress saves automatically to localStorage.
